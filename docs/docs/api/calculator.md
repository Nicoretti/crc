# Calculator

The `Calculator` combines a [configuration](configuration.md) with a `register` implementation and exposes two methods: `checksum` and `verify`.

!!! tip "Looking for available configurations?"

    See [configurations](../configurations.md) for all predefined configurations
    which can be passed to a `Calculator`.

!!! warning "Looking for a guide?"

    This page is the API reference. For a task oriented introduction see
    [calculating checksums](../usage/calculator.md).
